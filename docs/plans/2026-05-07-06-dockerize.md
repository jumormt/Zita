# Plan: Dockerize Zita + add dev container support

**Epic:** standalone (infra)
**Design:** none — direct execution. Two distinct artefacts: a production `Dockerfile` (multi-stage build → small runtime image) and a `.devcontainer/` config (development environment for VS Code Remote Containers / GitHub Codespaces).

## Summary

Make Zita runnable in containers without touching the host JDK/Maven/Python install, and let contributors open the repo in a fully-provisioned VS Code dev container. The runtime image bundles JAR + ruleset + Python batch scripts; the dev container additionally provides Maven, Kotlin tooling, and VS Code extensions for the Java/Kotlin/Python/XML stack.

**Decisions locked in:**

- **Multi-stage Dockerfile.** Stage 1 builds with `maven:3.9-eclipse-temurin-17`; stage 2 is `eclipse-temurin:17-jre-jammy` + `python3` (for batch scripts). Final image ≤ 350 MB.
- **`processing-java` deliberately omitted from the runtime image.** It's a Processing IDE component requiring an X server; would balloon the image. `DoesItBuildRule` will gracefully degrade (one extra "failed to build" violation per submission). Documented as a known limitation.
- **Dev container reuses Microsoft's `mcr.microsoft.com/devcontainers/java:1-17-jammy`** rather than building from scratch — already includes Maven, Git, common dev tooling. Python added via the `devcontainers/features/python:1` feature. Avoids maintaining a parallel Dockerfile.
- **Default entrypoint = `java -jar /app/Zita.jar`.** `--rules /app/rules.xml` is bundled but not the default arg (so users can supply their own ruleset by mounting). Batch invocations override the entrypoint to `python3`.
- **Image is unpublished.** No `docker push` step. Documentation shows `docker build` from a local clone.

### [ ] Task 1.1: `Dockerfile` (multi-stage)

- [ ] Stage 1 `builder`: `maven:3.9-eclipse-temurin-17`, COPY `pom.xml` first → `mvn dependency:go-offline` (cache layer), then COPY `src/`, then `mvn -B package -DskipTests`
- [ ] Stage 2 `runtime`: `eclipse-temurin:17-jre-jammy`, `apt-get install python3` (for scripts), COPY JAR + rules.xml + scripts/ from builder, set `WORKDIR /workspace`, `ENTRYPOINT ["java","-jar","/app/Zita.jar"]`
